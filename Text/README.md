# Text

Text extraction, manipulation, and searching capabilities.

## Samples

### AddGlyphs
Add individual glyphs to PDF pages.

### AddUnicodeText
Add Unicode text content to PDF pages.

### AddVerticalText
Add vertically oriented text to PDF pages.

### ExtractAcroFormFieldData
Extract text data from AcroForm fields.

### ExtractCJKTextByPatternMatch
Extract CJK text using pattern matching.

### ExtractTextByPatternMatch
Extract text from PDF pages using pattern matching.

### ExtractTextByRegion
Extract text from specific regions of PDF pages.

### ExtractTextFromAnnotations
Extract text content from PDF annotations.

### ExtractTextFromMultiRegions
Extract text from multiple defined regions of PDF pages.

### ExtractTextPreservingStyleAndPositionInfo
Extract text while preserving font style and position information.

### ListWords
List all words found on PDF pages.

### RegexExtractText
Extract text matching regular expression patterns.

### RegexTextSearch
Search for text using regular expression patterns.

### TextExtract
Extract all text content from PDF pages.
