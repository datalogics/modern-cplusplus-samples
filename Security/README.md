# Security

Digital signatures, redactions, and document security features.

## Samples

### AddDigitalSignatureCMS
Add a CMS-based digital signature to a PDF document.

### AddDigitalSignatureRFC3161
Add an RFC 3161 timestamped digital signature to a PDF document.

### AddRegexRedaction
Add redaction annotations based on regex pattern matching.

### Redactions
Apply redaction annotations to permanently remove content.
