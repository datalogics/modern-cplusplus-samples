# Annotations

Handling PDF annotations including marks, comments, and interactive elements.

## Samples

### Annotations
Create and manage various types of PDF annotations.

### InkAnnotations
Add freehand ink annotations to PDF pages.

### LinkAnnotation
Create hyperlink annotations within PDF documents.

### PolygonAnnotations
Add polygon-shaped annotations to PDF pages.

### PolyLineAnnotations
Add polyline annotations to PDF pages.
