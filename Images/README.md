# Images

Working with images in PDF documents including rendering, extraction, and manipulation.

## Samples

### DocToImages
Convert PDF pages to image files.

### DrawSeparations
Render color separation plates from PDF pages.

### DrawToBitmap
Render PDF pages to in-memory bitmaps.

### EPSSeparations
Generate EPS separation plates from PDF pages.

### GetSeparatedImages
Extract individual color separation images from PDF pages.

### ImageEmbedICCProfile
Embed ICC color profiles into PDF images.

### ImageExport
Export images from a PDF document to files.

### ImageExtraction
Extract embedded images from PDF pages.

### ImageFromStream
Create PDF images from data streams.

### ImageImport
Import external images into a PDF document.

### ImageResampling
Resample images in a PDF to change resolution.

### ImageSoftMask
Apply soft mask transparency to PDF images.

### OutputPreview
Preview color separations and output intent of a PDF.

### RasterizePage
Rasterize PDF pages to image buffers.
