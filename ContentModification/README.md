# Content Modification

Modifying existing PDF content including layers, annotations, and document structure.

## Samples

### Action
Work with PDF actions and triggers.

### AddCollection
Add a collection (portfolio) to a PDF document.

### AddQRCode
Add QR code images to PDF pages.

### ChangeLayerConfiguration
Modify the visibility configuration of PDF layers.

### ChangeLinkColors
Change the color of link annotations in a PDF.

### CreateLayer
Create optional content layers in a PDF document.

### ExtendedGraphicStates
Apply extended graphic state properties to PDF content.

### FlattenTransparency
Flatten transparent elements in a PDF document.

### LaunchActions
Create launch actions that open external applications.

### MergePDF
Merge multiple PDF documents into one.

### PageLabels
Add and modify page labels in a PDF document.

### PDFObject
Directly manipulate low-level PDF objects.

### UnderlinesAndHighlights
Add underline and highlight annotations to text.

### Watermark
Add watermark overlays to PDF pages.
