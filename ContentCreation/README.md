# Content Creation

Creating new PDF content including pages, elements, and graphic features.

## Samples

### AddElements
Add text, paths, and images to a PDF page.

### AddHeaderFooter
Add headers and footers to PDF pages.

### Clips
Apply clipping paths to PDF content.

### CreateBookmarks
Create and organize document bookmarks.

### GradientShade
Create gradient shading patterns in PDF.

### MakeDocWithCalGrayColorSpace
Create a document using CalGray color space.

### MakeDocWithCalRGBColorSpace
Create a document using CalRGB color space.

### MakeDocWithDeviceNColorSpace
Create a document using DeviceN color space.

### MakeDocWithICCBasedColorSpace
Create a document using ICC-based color space.

### MakeDocWithIndexedColorSpace
Create a document using Indexed color space.

### MakeDocWithLabColorSpace
Create a document using Lab color space.

### MakeDocWithSeparationColorSpace
Create a document using Separation color space.

### NameTrees
Create and manipulate PDF name trees.

### NumberTrees
Create and manipulate PDF number trees.

### RemoteGoToActions
Create GoTo actions that navigate to remote documents.

### WriteNChannelTiff
Write N-channel TIFF images from PDF content.
