# Information Extraction

Extracting and querying document structure and metadata.

## Samples

### ListBookmarks
List all bookmarks in a PDF document.

### ListInfo
Display and modify PDF document information properties.

### ListLayers
List optional content layers in a PDF document.

### ListPaths
List path elements on PDF pages.

### ListStructTree
Walk the logical structure tree of a tagged PDF document and print each element's
struct type, kid entries (child elements and marked-content references), and
parent chain. Also demonstrates `StructTreeRoot::find_element_by_id`.

### Metadata
Read and write XMP metadata in a PDF document.
